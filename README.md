# 꼬마별 스튜디오 홈페이지

아기 탄생·성장 기념 맞춤 포스터 소개 페이지입니다. 결제는 스마트스토어, 아기 정보 접수와 상담은 카카오톡 채널에서 처리합니다.

## 1. 내용 바꾸기

`index.html` 맨 아래 `CONFIG` 부분만 고치면 됩니다.

- `links`: 스마트스토어 상품 링크 4개, 카카오톡 채널, 인스타그램, 개인정보처리방침 주소
- `prices`: 상품 가격
- `business`: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처

링크가 비어 있으면 버튼을 눌렀을 때 "링크 준비 중" 안내가 뜹니다.

## 2. 사진 넣기

1. 저장소에 `images` 폴더를 만들고 사진을 올립니다. (예: `images/sample1.jpg`)
2. `index.html`에서 `<div class="ph" ...>탄생 포스터 사진</div>`을 찾아
   `<div class="ph"><img src="images/sample1.jpg" alt="탄생 포스터 액자"></div>`처럼 바꿉니다.
3. 사진은 정사각형, 한 장에 500KB 이하로 줄여서 올리면 빠르게 열립니다.

후기(`[실제 후기 내용]`)와 자주 묻는 질문의 `[ ]` 부분도 실제 내용으로 채워주세요.

## 3. 배포하기 (GitHub + Netlify 또는 Cloudflare Pages)

1. GitHub에서 새 저장소를 만들고 `index.html`, `README.md`를 올립니다.
2. Netlify(또는 Cloudflare Pages)에 GitHub 계정으로 가입합니다.
3. "새 사이트 → GitHub 저장소 가져오기"로 이 저장소를 고릅니다.
   - 빌드 명령: 비워두기
   - 배포 폴더: `/` (루트)
4. 몇십 초 뒤 사이트 주소가 생깁니다. 이후 GitHub에서 파일을 고치면 자동으로 다시 배포됩니다.
5. 도메인을 샀다면 호스팅 서비스의 도메인 설정에서 연결합니다.

> GitHub Pages는 약관상 상거래 목적 사이트 운영이 허용되지 않으므로 사용하지 않습니다. 호스팅 서비스의 무료 플랜 상업적 이용 조건은 가입 전에 확인하세요.

## 4. 아기 정보를 다룰 때 주의할 점

- 아기 이름·생일 같은 개인정보를 받으므로 **개인정보처리방침** 페이지를 만들어 `CONFIG.links.privacy`에 연결하세요.
- 작업 사례 사진은 부모님 동의를 받고, 이름·생일 등은 가린 뒤 올리세요.
- 받은 정보는 제작 후 정해둔 기간이 지나면 지우고, FAQ의 `[ ]일`에 그 기간을 적어두세요.
